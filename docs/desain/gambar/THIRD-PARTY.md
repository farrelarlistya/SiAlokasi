# Lisensi Pihak Ketiga — SiAlokasi

Dokumen ini mencatat pustaka utama yang dipakai aplikasi. Semua lisensi mengizinkan
pemakaian internal dan demo. Versi pasti mengikuti `package-lock.json`.

| Pustaka | Kegunaan | Lisensi |
| :--- | :--- | :--- |
| React & React DOM | Antarmuka web | MIT |
| Vite | Build & server pengembangan | MIT |
| Tailwind CSS | Token tema & utilitas tampilan | MIT |
| TanStack Query | Pengambilan & cache data | MIT |
| React Router | Navigasi halaman | MIT |
| Leaflet | Kanvas peta interaktif | BSD-2-Clause |
| react-leaflet | Jembatan Leaflet untuk React | MIT |
| Lucide | Ikon antarmuka & bantuan | ISC |
| Fastify | Server API | MIT |
| @fastify/cookie | Pembacaan & penulisan cookie sesi | MIT |
| @fastify/cors | Pengaturan akses web ke API | MIT |
| Prisma | ORM & migrasi database | Apache-2.0 |
| PostgreSQL | Database | PostgreSQL License |
| Zod | Validasi data bersama | MIT |
| tsx | Menjalankan TypeScript di server | MIT |
| Vitest | Unit test | MIT |
| Plus Jakarta Sans | Font judul & isi | SIL Open Font License 1.1 |
| IBM Plex Mono | Font nomor izin/kode lacak | SIL Open Font License 1.1 |
| OpenStreetMap | Data & tile peta | ODbL 1.0 |
