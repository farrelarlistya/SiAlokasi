## 4. Pemeriksaan Kualitas Desain

- [x] Tidak ada teks di bawah 16 px pada board.
- [x] Tombol utama dan target sentuh menggunakan tinggi 48 px (≥44 px).
- [x] Tombol biru memakai `#2563EB` dengan teks putih (kontras ≈5,5:1).
- [x] Status selalu chip berwarna **+ teks**, bukan warna saja.
- [x] Tidak ada dialog bawaan browser di rancangan.
- [x] Setiap layar punya jalur keluar (tombol kembali/batal).
- [x] Font yang dipakai tersedia (`Plus Jakarta Sans`, `IBM Plex Mono`) — tidak ada peringatan font hilang di FigCraft.
