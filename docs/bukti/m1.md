## 1. Ringkasan

M1 membangun kerangka aplikasi dari nol sampai bisa dijalankan, komponen antarmuka wajib, dan data awal bersih. Semua halaman masih berupa pondasi; alur masuk, peta interaktif, dan alur laporan menyusul di M2–M3.

| Yang dibangun | Lokasi |
| :--- | :--- |
| Monorepo npm workspaces | `package.json`, `apps/*`, `packages/*` |
| Tipe domain, skema Zod, alur status, Haversine, format | `packages/shared` |
| API Fastify + Prisma + PostgreSQL 17 | `apps/api` |
| Skema database lengkap (PRD §6.1) + migrasi awal | `apps/api/prisma` |
| Seed bersih 10 bantuan / 8 kecamatan / 3 posko / 3 akun | `apps/api/prisma/seed.ts` |
| `ClockService` + reset demo | `apps/api/src/clock.ts`, `npm run demo:reset` |
| Token warna Tailwind v4 (`@theme`) | `apps/web/src/styles/theme.css` |
| 6 komponen wajib + halaman pemeriksaan `/ui` | `apps/web/src/components`, `apps/web/src/pages/UiKitPage.tsx` |
| Beranda publik tahap pondasi | `apps/web/src/pages/HomePage.tsx` |
| Skrip database & verifikasi | `scripts/db.mjs`, `apps/api/scripts/verify-m1.ts` |

## 5. Catatan Teknis

- **PostgreSQL 17 lokal** dipakai tanpa PostGIS. Peran `sialokasi` diberi hak `CREATEDB` agar `prisma migrate dev` dapat membuat shadow database.
- **Migrasi awal** mencakup seluruh entitas PRD §6.1 agar M2–M4 tidak perlu mengubah fondasi tabel.
- **Font lokal** dimuat lewat paket `@fontsource` sehingga tidak bergantung pada internet saat demo.
- **Warna status** `DIPERIKSA` memakai token baru `--color-violet` yang ditambahkan ke `docs/desain/design.md` §2.2.
- **Ikon bantuan** disimpan sebagai nama ikon Lucide di data master; render ikon final menyusul di M3.
