## Tambahan: sapuan "tanpa kalimat penggantung" (2026-11-13, putaran kedua)

Pemilik proyek memberi daftar sembilan kalimat yang menurutnya tidak perlu, lalu meminta polanya
dipatok menjadi gaya proyek dan disapu ke seluruh halaman.

### Analisis pola

Kesembilan kalimat itu ternyata termasuk lima kategori yang sama:

| Kategori | Contoh dari daftar pemilik |
| :-- | :-- |
| Tagline di bawah judul yang hanya mengulang langkah | "Tentukan titik dan radius, lalu lanjut ke faktor." · "Isi faktor lapangan, lalu hitung estimasi." |
| Kalimat alasan / penenangan (editorial) | "Faktor dipakai untuk menghitung kebutuhan, bukan untuk menilai siapa yang salah." |
| Contoh pada `hint` yang mengulang label | "Sebutkan sendiri, misalnya: tanah longsor atau letusan gunung." |
| Penjelas status yang mengulang chip status | "Masih bisa disunting sebelum diajukan." · "Sudah terkunci dan menunggu keputusan pimpinan." · "Distribusi sudah dilakukan" |
| Sufiks kualifier & penghitung jumlah | "Kecamatan terdampak · otomatis" · "Lima laporan terakhir dari akun Anda." |

### Yang dihapus

**31 kalimat dihapus dan 5 dipendekkan di 19 berkas** (`apps/web/src`):

| Halaman | Yang berubah |
| :-- | :-- |
| Beranda publik | tagline "Pilih kejadian di peta atau daftar untuk melihat rinciannya." |
| Buat laporan | tagline "Tentukan titik dan radius…", hint "Sebutkan sendiri…", label "Kecamatan terdampak · otomatis" → "Kecamatan terdampak" |
| Dasbor petugas | 3 `hint` status pada kartu ringkasan + "Lima laporan terakhir dari akun Anda." |
| Faktor & estimasi | `brief` judul + `brief` bagian "Faktor lapangan" |
| Ajukan laporan | `brief` "Periksa rincian bantuan, lalu ajukan ke pimpinan." |
| Dasbor pimpinan | `brief` judul, `brief` "Antrian keputusan", kalimat "Jumlah dihitung terpisah per jenis…" |
| Tinjau laporan | 2 `brief` + `hint` "Alasan perubahan"; `hint` penolakan dipendekkan jadi "Minimal 5 karakter." |
| Izin distribusi | `brief` "Periksa dokumen…", `hint` "Alasan koreksi", kalimat riwayat koreksi dipendekkan |
| Lacak status | tetap mempertahankan "Kode diberikan petugas saat laporan dibuat." (informasi unik) |
| Masuk / daftar | `brief` langkah email, 2 `hint` pada formulir daftar |
| Admin (akun, ringkasan, wilayah, jenis bantuan, audit) | 6 `brief` judul halaman |
| Panel demo | 2 `brief`; peringatan reset **tetap dipertahankan** |
| Komponen peta posko | kalimat dipendekkan jadi "Klik peta untuk memindahkan titik posko." |
| Pustaka komponen (`/ui`) | 1 `hint` dipendekkan jadi "Boleh dikosongkan." |
