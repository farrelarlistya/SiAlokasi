## 1. Ringkasan

M2 menambahkan pintu masuk untuk tiga peran, sesi cookie httpOnly, pemeriksaan hak akses di server, pengelolaan akun, serta CRUD data master yang tidak menghapus riwayat. Peta publik P1 dan pemilih koordinat posko memakai Leaflet.

| Yang dibangun | Lokasi |
| :--- | :--- |
| Skema auth, pendaftaran, filter publik, ikon bantuan | `packages/shared/src/schemas.ts`, `auth.ts`, `domain.ts` |
| Tabel `sessions`, `User.regionId`, `Region.isActive` | `apps/api/prisma/schema.prisma` + migrasi `m2_akun_dan_data_master` |
| OTP `123456`, sesi cookie, RBAC 401/403 | `apps/api/src/routes/auth.ts`, `src/lib/{auth,rbac}.ts` |
| CRUD akun, jenis bantuan, kecamatan, posko | `apps/api/src/routes/admin-*.ts` |
| Ringkasan admin/pimpinan/petugas + stok read-only | `apps/api/src/routes/{admin-summary,pimpinan,petugas,stock}.ts` |
| Peta publik + filter jenis bencana/kecamatan | `apps/api/src/routes/public.ts`, `apps/web/src/pages/HomePage.tsx` |
| Halaman masuk & daftar | `apps/web/src/pages/auth/` |
| Dasbor petugas, pimpinan, admin D1–D5 | `apps/web/src/pages/{petugas,pimpinan,admin,shared}/` |
| Peta Leaflet, marker radius, pemilih titik posko | `apps/web/src/components/map/`, `styles/theme.css` |
| Seed demo dengan wilayah petugas | `apps/api/prisma/seed.ts` |

## 5. Catatan Teknis

- **Session** dan `User.regionId` ditambahkan lewat migrasi `20261108032412_m2_akun_dan_data_master`; keputusan dicatat di `docs/adr/0004-autentikasi-otp-dan-sesi-cookie.md`.
- **Sesi 12 jam** disimpan sebagai hash; akun nonaktif langsung kehilangan akses dan seluruh sesinya dihapus.
- **`DEMO_MODE=true`** menerima `123456` untuk akun aktif; di luar mode demo, kode acak hanya muncul di log server (adapter simulasi).
- **Nonaktif ≠ hapus** diterapkan pada `AidItem`, `Posko`, dan `Region`; relasi laporan/rekomendasi lama tidak dihapus.
- **Peta** memakai token warna lewat kelas `.map-*` di `theme.css`; marker dibuat dengan `CircleMarker` agar tidak bergantung pada berkas ikon Leaflet.
- **`demo:reset`** mengembalikan tepat 10 bantuan, 8 kecamatan, 3 posko, 3 akun demo, 0 transaksi, dan 0 sesi.
- **Pimpinan & Petugas** sudah punya kerangka dasbor; alur pembuatan laporan dan tinjauan keputusan menyusul di M3.
